#  Gestor de Tareas (Task Manager)

Aplicación web para la gestión de tareas diarias (CRUD), desarrollada con Java y Spring Boot en el backend, conectada a una base de datos MySQL y con un frontend dinámico usando Thymeleaf y Bootstrap.

---

##  Tecnologías Utilizadas

- **Backend:** Java 25, Spring Boot 3.2.0, Spring Data JPA
- **Base de Datos:** MySQL
- **Frontend:** HTML5, CSS3, Bootstrap 5, Thymeleaf
- **Herramientas de Construcción & Control de Versiones:** Maven, Git, GitHub

---

##  Funcionalidades

- **Crear Tareas:** Añade nuevas tareas con descripción.
- **Listar Tareas:** Muestra las tareas registradas con su estado actual.
- **Marcar como Completada / Pendiente:** Cambia el estado dinámicamente mediante un botón interactivo.
- **Eliminar Tareas:** Elimina tareas completadas o descartadas.
